# 0009. Custom themes: stored as JSON text, contrast advised, prompts never kept

Status: Accepted, 2026-10-23.

## Context

Every built-in theme holds 4.5:1 text and 3:1 non-text contrast (`tests/contrast.test.js`). People can also make up to five custom themes, by hand or generated by Claude Haiku from a short description.

## Decision

- Custom themes are stored as JSON text (`customThemes`), so older builds compare them by value and never restamp them.
- A custom theme joins the dark or light pick by its background's luminance.
- The editor notes contrast under AA at the token, but never blocks a save. Custom themes are the one exception to the contrast floor.
- The theme-generation prompt is never logged or stored. Generation is limited to 20 a day (`theme_generations`).

## Consequences

A theme format change has to stay readable as JSON text by older builds.
