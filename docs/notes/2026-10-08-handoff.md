## Conventions this sprint set

- **Branches and PR bodies.** One feature per branch, named `claude/<slug>`. PR bodies use What / Changes / Screenshots / Tests.
- **Your branches.** Nothing is pushed to a branch you're editing (#19 now).
- **Keeping branches current.** After each merge to master, master is merged into every open branch that needs it. History is never rewritten: no rebase, amend or force-push. So two commit messages with no blank line after the subject stay as they are (9a762a8 on #61, 25a8ea4 on #51).
- **Screenshots** are written to `docs/screenshots/<slug>/` only with `SCREENSHOTS=1`. Without it they go to Playwright's output folder, so normal test runs don't rewrite committed images. Screenshot specs type at about 70 ms per key so the images show believable speeds.
- **Browser tests:**
  - Run them with `CI=1 CHROMIUM=/opt/pw-browsers/chromium E2E_PORT=<unique port> npx playwright test <spec> --workers=1`. `CI=1` stops Playwright reusing a server another agent started.
  - Give each parallel run its own port, and avoid 6000 and 6665–6669, which Chromium refuses as unsafe.
  - **Never `pkill` the node server.** One agent did, and it killed every other agent's test server.
  - Open settings with `details.preferences > summary` or `openSettings()`. `details.preferences summary` also matches the group #21 nests inside it.
