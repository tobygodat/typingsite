Implemented in the native browser app without new runtime dependencies or database schema changes. Verification used Node 24.19.0 and Chromium 151.0.7922.173 on Debian 13. Account tests use FakeSupabase; no test data was sent to the live project.

## Behavior covered

| Area | Verified behavior |
| --- | --- |
| Progress | Filters isolate exact conditions; daily, interrupted and drill runs do not enter practice trends. WPM/accuracy chart points open saved run details by keyboard. Weekly medians require both weeks and show run counts. Undated records appear only in All saved runs. |
| Comparisons | Expandable before/after scores, skipped/completed drill information, timing sample limits, and practice-again actions. Older records without snapshots explicitly report missing details. |
| History | 1,000 compact summaries outlive 24 full traces; pattern data is capped at 120 summaries. Account reload retains the new records. Thirty summaries with no full traces still render and offer an explicitly standalone drill. |
| Training | A recurring target needs sufficient observations across multiple compatible runs. Clean timing also needs at least ten intervals per contributing run. Immediate retests do not supply later revisit observations. A retained current-corpus baseline opens a drill and fresh compatible retest. |
| Corpus | 39 unique original quotes, with at least three fresh options in every short/medium/long and gentle/steady/precise bucket. Exhaustion refuses a fresh comparison; unsupported filters explain and recover. Real-word drills supply 1,600 words. |
| Daily | UTC selection is stable within the day, independent of practice settings, and changes at midnight. Repeat attempts are labelled. Account results survive reload, remain separate from practice bests, and omit interrupted attempts. Returning text after the 14-day cycle keeps its identity and is distinguished from a first attempt on that date. |
| Clear/Undo | Includes daily history and compact summaries. Guest history disappears on reload. |
| Layout | New views fit 320px without sideways scroll. The narrow result-number token fixes the earlier run-card overflow. Existing typography, reduced motion, local two-player challenge and palette checks pass. |

## Limits

Verification used Chromium and a fake account service, not Firefox/WebKit, physical input latency or a live multi-device account. Daily results are personal observations, not a trusted public leaderboard. Quote difficulty remains descriptive. Pattern counts and immediate retests do not establish lasting learning effects. Account sync still uses the existing whole-profile last-writer-wins behavior.
